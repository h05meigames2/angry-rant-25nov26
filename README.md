# Angry Rant — The Office Printer

A short, funny rant about the office printer: the tiny bureaucratic gatekeeper that has never once in its life simply printed. It jams, runs out of toner, or demands a firmware update in the five minutes before a deadline — and treats its one job as a personal insult.

Entry for the [make.fun Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

## How to run

```bash
python3 main.py
```

This writes the rant to `/output/entry.txt` (one text, 1–400 characters, UTF-8, no trailing newline).
